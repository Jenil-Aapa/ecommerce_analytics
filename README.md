# Ecommerce Analytics

This is a MySQL SQL practice project based on an ecommerce database.

I created this project to practice SQL queries and prepare for Data Analyst interviews. The project contains database setup, 110 SQL questions with solutions, and additional interview challenges.

## Project Structure

```text
ecommerce_analytics/
│
├── README.md
│
├── 01_ecommerce_analytics_database_setup.sql
│
├── 02_ecommerce_analytics_questions_01-110.sql
│
└── ecommerce_analytics_question_bank.md
```

## Files

### 01_ecommerce_analytics_database_setup.sql

Contains the database and table setup for the ecommerce project.

It includes the tables, relationships, and sample data used for practicing the SQL queries.

### 02_ecommerce_analytics_questions_01-110.sql

Contains my SQL solutions for [110 questions](02_ecommerce_analytics_questions_01-110.sql).

The questions cover different SQL concepts, starting from basic queries and going up to advanced Data Analyst interview questions.

Topics include:

* SELECT and WHERE
* ORDER BY and LIMIT
* DISTINCT
* Aggregate Functions
* GROUP BY
* HAVING
* JOINs
* CASE WHEN
* Subqueries
* CTEs
* Window Functions
* Date Functions
* Revenue and Profit Calculations
* Business Analysis

### ecommerce_analytics_question_bank.md

Contains the complete list of [110 questions](ecommerce_analytics_question_bank.md) and 10 additional interview challenges.

I use this file to practice the questions first and then check my solutions in the SQL file.

## Some Business Questions

The project includes questions such as:

* Who are the top 5 customers by revenue?
* Which product generates the highest revenue?
* Which category generates the highest revenue?
* Which customers have never purchased anything?
* What is the monthly revenue trend?
* What is the average order value?
* Which product has the highest profit margin?
* What are the top 3 products in each category?
